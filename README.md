# 圆锥曲线小工具

一个用纯 C 语言编写的命令行交互工具，用于计算圆锥曲线（圆、椭圆、双曲线、抛物线）的各类几何性质与公式。

## 功能

- **圆**：周长、面积、标准方程/一般方程互化、阿波罗尼斯圆
- **椭圆**：标准方程、几何性质、点与椭圆位置关系、直线与椭圆交点、中点弦斜率公式、弦长公式
- **双曲线**：标准方程、几何性质、直线与双曲线交点、中点弦斜率公式、弦长公式（含渐近线平行判断）
- **抛物线**：标准方程、几何性质、直线与抛物线交点、中点弦斜率公式、弦长公式
- **圆锥曲线统一定义**：第二定义及准线

## 编译与运行

```bash
gcc conic_tool.c -o conic -lm
./conic
```

## 使用示例

运行程序后，通过菜单选择曲线类型并输入参数即可：
- 选择 `1` 进入圆的计算
- 选择 `2` 进入椭圆的计算
- 选择 `3` 进入双曲线的计算
- 选择 `4` 进入抛物线的计算
